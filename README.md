# Drift

A calm, fast, privacy-minded browser for macOS, built on WebKit.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/manu-tech-code/drift-releases/main/install.sh | bash
```

Or download the latest `.dmg` from the [Releases](../../releases/latest) page and drag Drift to Applications.

Drift checks for updates by itself (Drift → Check for Updates…) and installs them only after verifying their signature.

Requires macOS 15 or later.
